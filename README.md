# Lego\_Dataset\_PowerBI\_Analysis



Load , clean, transform and analyze Lego Sample Dataset, and generate POWER BI report/Dashboard.



Performed trend analysis , Price vs Number of Piece analysis , Theme of the decade Analysis

and Cost impact on manufacturing License of set.



#### About Dataset:



Dataset is available free to download at location: https://mavenanalytics.io/data-playground



It contains the information about LEGO sets released from 1970 to 2022.

It has 18,459 records in single table with 14 columns.



Objective analyzed are:



•	How many LEGO sets have been released since 1970? Is there any noticeable  trend?

•	Is there a relationship between the price of a set and its number of pieces?

•	Which has been the most popular theme in each decade?

•	Are LEGO minifigures most closely tied to licensed sets?
